# Changelog

## 0.2.0 - 2026-10-30
- The tile shows the name you gave it on the screen.
- With **Walk to the stop** set, the tile now tells you when to leave ("Leave in 12 min", then "Leave now") instead
  of adjusting the main countdown; the main number is always the bus's own departure time.

## 0.1.0 - 2026-10-30
- First version: the next departure of a stop you already have as an Entur sensor in Home Assistant, with the one
  after it, live on the tile.
